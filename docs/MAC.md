# Mac 安装与实测

目标：macOS 14 或更高，Apple Silicon（M1/M2/M3/M4 等 arm64），不支持 Intel Mac。

1. 下载私人 Release 的 `macos-arm64.zip`，完整解压，拖动 `.app` 到“应用程序”。不要从压缩包或临时挂载位置直接使用登录启动。
2. 核对 SHA256 后双击。若 macOS 拒绝未公证应用，先尝试打开一次，然后在系统设置 → 隐私与安全性中找到对应程序的“仍要打开”，按系统说明确认。
3. 如果系统明确提示文件损坏，先停止运行、核对下载和校验和，不要关闭全局 Gatekeeper。首版不提供 Apple Developer ID 公证，受管理的公司电脑可能无法放行。
4. 首次选择本机保存目录；默认快捷键 ⌘⌥1～5。设置中可换成其他支持的组合键，系统冲突会明确提示。
5. 较新 macOS 可能请求粘贴权限；macOS 14 不一定有此弹窗。拒绝后收集器会暂停并提示；系统允许后点击“恢复”并重新复制，不回填旧剪贴板。

不会要求全局键盘监听或屏幕录制权限来实现热键；使用 Carbon RegisterEventHotKey 注册组合键，不采集其他按键。截图请用 macOS 自带截图工具选择“复制到剪贴板”，或用 Control+Shift+Command+4（具体组合受你的系统设置影响）。

## 必须由真实 Mac 用户完成的验收

- 切到浏览器，窗口关闭只留菜单栏时连续复制中文、链接、富文本和截图；每次无声提示且卡片内容正确。
- Finder 复制多个文件，检查附件副本与原始文件不变。
- 修改热键、测试系统占用提示、重启后仍有效；中文输入法下再次测试。
- 使用 Typeless／系统听写，检查来源是否可识别；来源未知时用暂停＋单次收集规避干扰。
- 若系统提供粘贴授权开关：先拒绝、确认提示且无假成功，再恢复授权继续。
- 最小化、关闭、从 Dock／菜单栏唤醒、明确退出；退出后热键应释放。
- 登录启动默认关闭；需要时显式开启，重启验证后再决定保留。

Actions 的 Mac 原生测试／打包烟测不能替代这些实机验收，尤其不能证明 Typeless 和系统隐私授权流程已经通过。
