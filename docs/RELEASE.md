# v0.1.0 预览版

中文独立连续收集器：可选择 Vault／普通目录，自定义全局快捷键、模板与命名，支持连续收集、暂停、个人感想、撤销、旧卡续写及配置迁移。

Windows x64 与 macOS 14+ Apple Silicon 分平台构建。附 ZIP、SHA256 和实际打包程序烟测报告；测试仅使用合成资料库。无需安装 Python，旧收集器无需替换。

**这不是稳定版。** 自动测试与原生打包烟测不代表你的真实 Mac 已验收。Mac 授权、后台采集、中文／语音输入及实际热键仍请按 docs/MAC.md 验证；Windows 的真实输入软件和实际热键同样需要用户确认。

Mac 为自用 ad-hoc 签名、未公证，首次系统放行说明见文档；不要关闭全局系统安全检查。程序不上传资料、不内置云同步或 AI 入库；同卡仅支持单设备写入。
