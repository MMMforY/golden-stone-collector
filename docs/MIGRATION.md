# 配置与跨电脑迁移

## 换电脑

1. 原电脑“设置 → 导出配置”。导出只包含行为设置、模板和两平台热键，不带实际笔记、Vault 路径、最近目录或登录启动状态。
2. 在新电脑下载并解压对应平台程序；配置不需要放进 Obsidian，也不要把程序包放进会同步的附件目录。
3. “设置 → 导入配置”，再选择新电脑上 Vault 的实际根目录，然后保存。选择普通 Markdown 文件夹也可以。
4. 试录一张合成卡，检查图片和命名。若路径变化，在设置重新选择，不必改代码。

笔记同步是另一件事。本程序不内置云同步、不复制整个 Vault；可由你现有的同步工具负责。在另一台电脑上收集前应等待资料同步完成，避免同时写同一张卡。

## 从旧版迁移

设置中的“导入配置”接受旧版 JSON（含 `启动快捷键`、`停止快捷键`、`备注快捷键`等中文字段）。沿用 Windows 自定义热键与相关高级选项，Mac 使用自己的配置。保存前仍需选择本机 Vault。

导入保存时，已有独立版 `settings.json` 会复制成 `settings.before-时间.json`。不会写回旧版 JSON，不修改旧版脚本／启动入口，也不移动旧笔记。首次导入时若独立版尚无配置文件，则没有需要备份的旧文件。

## 本机配置

- Windows：`%LOCALAPPDATA%/GoldenStoneCollectorStandalone/settings.json`。
- Mac：`~/Library/Application Support/GoldenStoneCollectorStandalone/settings.json`。
- 日志由系统应用日志目录保存；不记剪贴板正文，只记运行状态／错误。重命名等错误可能带文件路径。不要随意公开日志和配置备份。

恢复备份：退出独立版，先保留当前 `settings.json`，将所需 `settings.before-*.json` 复制为 `settings.json`，再启动。登录启动属于系统设置：若不想保留，退出前在设置取消勾选。

原版可随时重新启动。独立版只是另一套入口，没有替换原版；关闭独立版后，原快捷键资源释放。
