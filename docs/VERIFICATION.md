# 预览版验证边界

本项目采用合成数据和临时资料库测试；不接触用户原 Vault。`tests/test_legacy.py` 是原收集器的合成回归场景，去掉旧的固定库标记和模板路径要求。

自动测试覆盖：混合文字／HTML／图片／文件、原文旁证与来源标记、个人感想连续追加、撤销及外部编辑保护、双层重命名与失败回滚、旧卡续写、不同名称根目录、路径逃逸拦截、暂停和恢复不补录、来源过滤、失败不报成功、热键冲突回退、配置迁移和保存失败回退、设置界面、最小化与窗口关闭策略、原生热键注册冲突。

发布包的 `smoke-*.json` 为 PyInstaller 程序实际运行合成读写／原生接口的报告。CI 测试明细在 Actions 的 `test-results.xml` 中。

尚需人工确认：Windows / Mac 在其他应用实际按键的唤醒稳定性，Typeless 各版本的剪贴板行为，Mac 系统粘贴授权、中文输入、菜单栏长期后台运行及睡眠唤醒。原生热键注册成功不等于每一种键盘、Fn 设置和软件环境都已经实测。

验收前保持 v0.1.0 预览；退出新版即可继续使用原版。不要同时运行两个版本写同一张卡。
