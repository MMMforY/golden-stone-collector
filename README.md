# Golden Stone 连续收集器 · 独立版

一个中文、本地优先的连续收集入口。复制文字、链接、富文本、图片或文件，持续写入同一张 Markdown 资料卡。不依赖 Obsidian 运行，不进行 AI 解读或自动归档。

**v0.1.0 为预览版，不是稳定版本。** 支持 Windows x64、macOS 14+ Apple Silicon。首次双击选择一个资料库／普通文件夹，此后记住本机位置。开机启动默认关闭。

## 下载与启动

从本私人仓库的 **Releases** 下载对应系统的 ZIP（需登录获授权的 GitHub 账号）。

- Windows：完整解压，双击 `GoldenStoneCollector/GoldenStoneCollector.exe`。不要只移动 exe，`_internal` 需要保留。不需要安装 Python。
- Mac：解压后把 `GoldenStoneCollector.app` 拖入“应用程序”，双击。首版为自用的临时签名，未做 Apple 公证；仅在确认下载来自本仓库且校验和匹配后，按照系统设置 → 隐私与安全性中的“仍要打开”流程放行。见 [Mac 验证与放行](docs/MAC.md)。
- 不会覆盖、卸载或停止旧收集器。两个版本的默认热键可能冲突：先退出旧版，或在独立版设置中录入另一组。

## 一次完整使用

1. 打开设置，选择 Vault 根目录，或普通 Markdown 文件夹。默认存入 `00-inbox/待整理资料`。
2. 点击“开始收集”或按开始快捷键。**此刻剪贴板里已有的内容不会补录。**
3. 在其他应用复制内容／复制截图；每次真正写入后，显示无声提示。图片进入同卡“附件”文件夹。
4. “个人感想”接在最近一项后；再次写感想会续写同一段。误收可“撤销最近一项”，连同该项的感想及本次复制出的附件一起撤销，不删除原始外部文件。
5. “暂停”期间不收集，恢复时也不补录；“单次收集”会明确收一次当前剪贴板，在暂停期间也可用，且允许重复收同一内容。
6. “结束收集”后输入一个标题，**文件夹与 Markdown 文件一起命名**；正文不重复放大标题。确认后打开 Obsidian；未识别到 Obsidian Vault 时打开文件夹。
7. 最近资料卡可打开、续写或统一重命名。也可直接在 Obsidian 编辑。外部编辑后，不安全的撤销会被拒绝。

只收文件，不递归复制文件夹；文件夹复制保存的是本地路径引用。复制多个文件会作为一项收集，附件为副本。网页远程图片链接不自动下载，离线需要自己复制图片／截图。

### 默认快捷键

| 动作 | Windows | Mac |
| --- | --- | --- |
| 开始 | Ctrl+Alt+F9 | ⌘⌥1 |
| 结束 | Ctrl+Alt+F10 | ⌘⌥2 |
| 个人感想 | Ctrl+Alt+F11 | ⌘⌥3 |
| 撤销 | Ctrl+Alt+F12 | ⌘⌥4 |
| 暂停／恢复 | Ctrl+Alt+F8 | ⌘⌥5 |
| 显示窗口／单次收集 | 默认不绑定 | 默认不绑定 |

设置中点击输入框后实际按键；退格或“清空”解除绑定。支持单组修饰键＋字母、数字、F1～F12 或导航键，不支持连招、仅 Fn 或媒体键。保存前检查内部重复、保存时实际向系统注册。失败恢复旧绑定并提示；若旧绑定也被其他程序占用，会告知恢复失败，此时使用窗口按钮。

Windows 最小化进入任务栏、关闭留在托盘；Mac 使用 Dock 和菜单栏、关闭仍驻留。双击应用可唤醒已有实例。托盘／菜单栏中明确“退出”才结束程序。

## 设置与迁移

见 [配置迁移](docs/MIGRATION.md)。设置包括路径、快捷键、正文模板及预览、年月分组、分钟命名前缀、窗口置顶、无声提示、登录启动与高级来源／重复抑制选项。

收集中可更改快捷键和界面；目录和模板须结束后修改。原始富文本／机器元数据选项在下一轮收集生效。录入设置或个人感想期间暂停自动读取，关闭对话框后不补录。

### 收集边界

- 剪贴板变化不等于人主动按了“复制”。语音输入、剪贴板管理器都可能写入剪贴板。
- Windows 默认忽略可识别的 `Typeless.exe`。Mac 只能根据来源应用提供的标识忽略；不会把前台应用假装成剪贴板写入者。未知来源保留 unknown。**无法承诺过滤所有语音输入干扰**，可暂停并用单次收集。
- 系统忙时稍后重试；写入失败不显示保存成功并暂停。Mac 拒绝粘贴权限／数据读取失败会提示，恢复权限后点击恢复并重新复制。
- 每张卡只支持同一设备单个写入者。不要在两台电脑同时续写同一张卡，也不要在原版与独立版同时写同一张卡；不做分布式锁或合并。
- 五项属性：状态、来源类型、上游来源、创建时间、下次回看。轻量标签及 `gs-card`／`gs-capture` v1 保持兼容，旧卡无需迁移。部分旧卡无机器标记时，续写仍保留原文。
- 保留原始 HTML 时可能包含原网页的链接或内容；不自动执行 HTML。配置和日志仅留本机，应用没有遥测或上传功能。

## 手动资料卡

不能使用程序时，可复制 [手动资料卡模板](templates/手动资料卡.md) 到 Vault 的模板目录，新建一张笔记再插入模板。不要把整张模板插入已有日记中。日期占位符可由 Obsidian 内置模板插件展开；普通编辑器中手动填写。附件由使用的编辑器管理。

## 开发与验证

Python 3.13：建立 venv，`python -m pip install -e ".[dev]"`，`python -m pytest -q`，`python -m golden_stone_collector`。原生接口按平台加载。

`python scripts/build.py` 在当前平台构建、运行合成包烟测并生成 ZIP 和 SHA256。Mac 必须使用 arm64 Python 和 M 系列机器。GitHub Actions 分平台验证与构建；推送 `v*` 标签发布预览包。

验收项目及已知限制见 [验证清单](docs/VERIFICATION.md)。源代码、测试、模板与文档可以入库；实际配置、笔记、运行日志和测试产物禁止提交。
